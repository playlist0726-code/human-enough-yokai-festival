- `prompts/`: 컨셉 이미지 제작에 사용한 프롬프트.

## 첫 캐릭터 작업 순서

한 캐릭터의 개별 시트 → 고정 게임 시점의 투명 배경 이미지 → 대기/제자리 걷기/홀리기 → 게임에서 확인 → 나머지 동작과 캐릭터 확장.

게임용 동작: 대기, 방향별 걷기, 포션 마시기, 홀리기 시작, 홀림 유지, 동료 가려주기, 정체 노출, 당황, 개별 등장, 성공.

캐릭터 단독 영상의 카메라와 크기를 일정하게 유지하고 배경을 분리한다. 반복 동작은 시작/끝이 연결되게 한다. 캐릭터 영상에 축제 배경, 다른 캐릭터, 포털, 자막 또는 줌을 합치지 않는다. 최종 게임용 프레임은 투명 배경, 동일 캔버스와 발 기준 위치로 준비한다. 프레임 크기와 재생 속도는 한 캐릭터를 게임에서 검증한 뒤 확정한다.

인간 NPC, 지도 구성 요소, 공통 포털/홀림 효과 및 UI 역시 후속 아트 작업에 포함된다. 이 목록은 완성 자산이 준비됐다는 의미가 아니다.
