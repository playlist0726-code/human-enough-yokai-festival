# 인간인 척! · 1인칭 축제 미니게임 전달 패키지 v02

이 ZIP은 현재 만든 웹 미니게임 시스템을 다른 게임 프로젝트에 옮기기 위한 소스 패키지입니다. 사격·금붕어 잡기·고리 던지기·타코야키·복주머니 뽑기·빙수 만들기 6종, 각 놀이의 1인칭 시점과 도구, 사람 운영자, 모바일 터치 조작, 7명 요괴의 손과 의상 표현을 포함합니다.

## 다른 채팅방에 전달하기

ZIP 전체를 업로드하고 아래 문장을 함께 전달하세요.

> 첨부 ZIP의 README.md와 INTEGRATION.md를 먼저 읽고, 이 1인칭 축제 미니게임 6종을 현재 작업 중인 내 게임에 연결해 줘. 놀이별 카메라·도구·터치 조작과 요괴별 손·의상 표현을 유지해 줘. 기존 게임 구조를 확인한 뒤 포차에서 시작, 종료 후 원래 게임으로 복귀, 캐릭터 선택, 보상 지급을 연결하고, 실제 플레이까지 검증해 줘. 이 ZIP에는 아직 호스트 게임용 시작·종료 메시지 API가 없으니 프로젝트에 맞게 추가해 줘.

## 실행하기

Node.js 18 이상이 있는 컴퓨터에서 압축을 푼 폴더를 열고 `npm start`를 실행한 다음 브라우저에서 `http://127.0.0.1:4174/`를 엽니다. 추가 패키지 설치나 빌드 과정은 없습니다. 종료는 실행 중인 터미널에서 Ctrl+C입니다.

Python 3이 있다면 대신 `python3 -m http.server 4174 --directory dist`로 실행해도 됩니다. `dist/index.html`을 파일로 직접 더블클릭하면 모듈 로딩이 제한될 수 있으니 HTTP 서버로 여세요.

휴대폰에서는 호스팅한 주소를 열거나 같은 Wi-Fi의 개발 서버에 접속합니다. 개발 서버를 외부 기기에서 열려면 `GAME_HOST=0.0.0.0 npm start`로 실행한 뒤 휴대폰에서 `http://컴퓨터의-LAN-IP:4174/`를 엽니다. 방화벽과 같은 네트워크 연결이 필요합니다. 휴대폰의 `127.0.0.1` 주소는 컴퓨터에 연결되지 않습니다.

## 들어 있는 것

- `dist/`: 바로 서비스할 수 있는 HTML·CSS·JavaScript 원본, 이미지, 로컬 Three.js 라이브러리
- `INTEGRATION.md`: 기존 게임에 연결할 위치, 규칙 API와 입력 형식, 현재 구현 범위
- `serve.mjs`, `package.json`: 설치 과정 없는 로컬 실행 도구
- `tests/`: 고리 던지기의 힘·조준 판정 검증 3개. `npm test`로 실행
- `THIRD_PARTY_NOTICES.md`, `dist/vendor/three/LICENSE`: 포함 라이브러리 고지
- `MANIFEST.sha256`: 전달 파일의 무결성 확인 목록

3D 장면과 손·운영자·도구는 Three.js 코드로 생성합니다. 별도 GLB·FBX·Unity·Unreal 프로젝트는 들어 있지 않습니다. 원래 협동 게임 전체, 7명 전체 애니메이션 제작팩도 이 미니게임 ZIP의 범위에는 포함하지 않았습니다.

현재 보상은 화면 안내와 로컬 도장 기록입니다. 본 게임의 인벤토리·요력·협동 서버 연결은 적용 대상 프로젝트에서 연결해야 합니다. 자세한 연결 지점은 INTEGRATION.md를 참고하세요.

게임 동작에 필요한 Three.js와 이미지는 로컬에 포함되어 있습니다. Google Fonts는 선택적 외부 요청이며, 연결되지 않으면 CSS의 대체 글꼴을 사용합니다. 데스크톱과 모바일 크기 브라우저 조작을 확인한 버전이며 실제 모든 휴대폰 기기의 성능을 보장하는 것은 아닙니다.
