# 인간인 척! — 산 위 축제 배경과 포차

기존 요괴 캐릭터와 함께 사용할 둥근 3D 렌더 스타일의 배경 콘셉트 이미지입니다. 동물의 숲에서 요청한 포근한 마을 분위기, 짧은 비율, 부드러운 입체감, 무광 장난감 질감을 기준으로 제작했습니다. 운영자와 손님은 인간이며, 요괴 캐릭터를 평범한 동물로 변경하지 않았습니다.

## 공통 아트 기준

- 살짝 내려다보는 3/4 시점. 테이블 위 도구와 손동작이 보이는 구도.
- 목재 골조, 천 차양, 종이등, 돌바닥, 붉은 난간. 푸른 밤빛과 따뜻한 조명.
- 각 포차마다 다른 운영자와 의상 색, 구별되는 놀이 도구와 경품.
- 운영자는 손님 응대·도구 준비·조리 등 실제 행동 중인 모습.
- 작은 물결, 풍선 반사, 얼음 가루, 김, 불꽃놀이 등 장면에 필요한 효과만 사용.
- 개별 포차 이미지에는 운영자와 손님, 주변 바닥과 배경이 포함됨. 투명 분리 에셋이 아님.

`prompts/`와 `prompt_manifest_v01.json`에 각 이미지의 최종 생성 프롬프트를 저장했습니다. 내장 이미지 생성 도구를 사용했습니다. 이미지 속 3D 표현은 렌더 스타일의 콘셉트 아트이며, 이 패키지에는 새 포차의 3D 모델 파일이 포함되지 않습니다.
