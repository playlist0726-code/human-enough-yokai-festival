# 인간인 척! · 달빛 축제 놀이터

일곱 요괴의 손과 축제 의상 소매로 직접 즐기는 1인칭 미니게임 체험판. 기존 협동 게임의 소스는 변경하지 않았습니다.

## 놀이별 시점과 조작

| 놀이 | 내 시점 | 조작 |
| --- | --- | --- |
| 코르크 사격 | 총 뒤에서 경품 선반을 바라봄 | 화면을 드래그해 조준, 발사 버튼. 총 반동과 코르크 발사 |
| 금붕어 건지기 | 수면 위에서 뜰채와 물그릇을 내려다봄 | 뜰채를 움직인 뒤 손을 떼거나 들어 올리기 버튼 |
| 고리 던지기 | 고리를 쥔 손에서 말뚝판을 바라봄 | 화면을 위로 당기거나 버튼을 길게 눌렀다 놓기. 세기와 좌우 조준으로 판정 |
| 타코야키 | 내 앞의 철판과 꼬치를 내려다봄 | 노릇한 반죽을 누르거나 조준 후 뒤집기 버튼 |
| 경품 뽑기 | 눈앞의 세 주머니에 손을 뻗음 | 원하는 주머니를 위로 끌어 올리기 |
| 빙수 | 빙삭기와 손잡이를 앞에서 바라봄 | 손잡이 주변을 원으로 돌리기. 12칸 후 주문 시럽 선택 |

- 미즈·폰·콘·스미·네무·아카리·카사의 손 색, 소매 색과 무늬를 반영.
- 놀이마다 다른 카메라 위치·내려다보는 각도·도구·인간 운영자.
- 휴대폰 세로 화면, 터치 및 키보드 조작, 효과음 선택, 성공 도장 로컬 저장.
- Space: 해당 놀이의 도구 사용. 방향키: 조준. 고리는 Space를 눌렀다 놓아 던짐.
- 빙수 손잡이 한 칸 버튼과 시럽 버튼은 원형 드래그의 대체 조작으로 제공.
- 낮은 화면 성능에서는 해상도와 그림자를 줄임.

dist 폴더를 정적 HTTP(S) 웹서버에서 제공하면 실행됩니다. 파일을 직접 더블클릭해서 실행하는 방식은 지원하지 않습니다. Sites 배포 정보는 .openai/hosting.json에 보관합니다.

## 제작 범위

현재는 캐릭터별 손과 소매를 별도로 구성한 1인칭 체험판입니다. 앞서 생성한 고품질 캐릭터 시트를 그대로 메시로 변환한 최종 모델은 아닙니다. 협동 본편의 보상 서버 연결이나 앱 설치 패키지는 포함하지 않습니다. 기존 본편은 ../yokai-festival/에 있습니다.

## 검증

- JavaScript 구문 검사.
- 고리의 실제 던지는 세기·조준·잘못된 입력에 대한 테스트 3개.
- 데스크톱과 390 × 844 세로 브라우저 화면에서 놀이별 시점 확인.
- 브라우저에서 조준 후 사격 명중, 위로 당긴 고리의 성공 판정, 주머니를 위로 잡아당기는 뽑기 성공 확인.
- 실제 iPhone/Android 기기에서의 성능은 별도 확인이 필요합니다.

Nintendo 자산이나 캐릭터는 포함하지 않습니다.
