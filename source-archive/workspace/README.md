# 인간인 척! — 캐릭터 아트와 동작 시안 v01

e.v.e games의 미즈·폰·콘·스미·네무·아카리·카사 제작 묶음.

## 보기

`index.html`을 브라우저에서 열면 캐릭터별 시트, 투명 기본 아트, 동작 시안, 생성 프롬프트와 원본을 선택할 수 있다. 압축 파일은 이 파일과 같은 폴더 구조를 유지해서 해제한다.

## 포함 파일

- 캐릭터별 시트 7종: 정면·좌우 측면·후면·게임 3/4, 표정 5종, 신체·포션·의상·능력 효과 확대. 네무는 포션 위치를 보정한 `nemu_sheet_v02.png`를 최신판으로 사용한다.
- 캐릭터별 투명 기본 아트 7종: `art/<캐릭터>/<캐릭터>_base_v01.png`. 이미지 생성 도구가 출력한 1254×1254 RGBA PNG이며 바닥 그림자는 없다.
- 분리된 바닥 그림자 7종: `art/<캐릭터>/<캐릭터>_shadow_v01.svg`. 게임 안에서 캐릭터 크기와 발 기준점에 맞춰 조정할 수 있는 별도 반투명 그림자다.
- 3D 동작 시안 총 91개: 캐릭터당 13개. 대기, 앞·뒤·왼쪽·오른쪽 제자리 걷기, 포션 마시기, 홀리기 시작, 홀림 유지, 동료 가려주기, 정체 노출, 당황, 등장, 성공.
- 투명 영상: `production/animations/<캐릭터>/<캐릭터>_<동작>_v01.webm`. VP9 alpha, 512×512, 24fps. MP4 확인용 버전은 배경이 들어간 별도 파일이며 투명하지 않다.
- 편집 가능한 3D 시안 원본 7종: `production/models/<캐릭터>_motion_study_v01.blend`. 하나의 모델에 모든 동작을 키프레임으로 저장하고 시작·끝 타임라인 마커를 붙였다.
- 캐릭터별 동작 기준·생성 프롬프트: `art/<캐릭터>/<캐릭터>_actions_v01.md`. 목적, 시작·끝 자세, 반복 여부, 권장 길이, 연기 포인트, 프롬프트, 파일 이름을 각 동작마다 정리했다.
- 신체 개수와 본모습·행동 위장 기준: `production/CHARACTER_RULES.md`.
- 기계 판독용 동작 목록: `production/action_manifest_v01.json`.
- 독립 HyperFrames 검토용 HTML 91종: `production/hyperframes/clips/`. 루트 `index.html`은 미즈 대기 동작이다.

## 아트와 동작 시안의 차이

시트와 투명 기본 아트는 제공한 참조에 맞춰 내장 이미지 생성 도구로 제작한 3D 렌더 스타일의 이미지다.

동작 영상은 캐릭터의 특이한 신체 구조와 연기를 검토하기 위해 별도로 재구성한 간단한 실제 3D 기하 모델을 사용한다. 시트의 최종 아트를 그대로 모델링하고 스킨 웨이트를 붙인 완성 게임 캐릭터와는 구분한다. 원본의 파츠 피벗과 키프레임은 수정할 수 있지만, 최종 게임용 메시·정식 스켈레톤·의상 시뮬레이션·엔진 임포트 완료를 의미하지 않는다.

모든 영상은 고정 카메라, 단독 캐릭터, 고정 캔버스, 동일 모델과 의상을 사용한다. 걷기의 root XY 이동은 0이며 실제 이동은 게임에서 처리한다. 등장 동작에는 축제 배경이나 포털을 합성하지 않았다. 반복 클립은 같은 동작 위상으로 시작하고 끝난다.

## 길이와 프레임

권장 길이는 기획 문서의 초 단위 값이며, 실제 영상은 24fps의 정수 프레임에 맞춰 반올림했다. 정확한 길이와 프레임 구간은 각 동작 폴더의 `metadata.json` 및 캐릭터의 `clips.json`에서 확인한다.

투명 PNG 프레임 시퀀스는 작업 폴더의 `production/animations/<캐릭터>/<동작>/frame_*.png`에 남겨 두었다. 압축 묶음에서는 용량을 줄이기 위해 원시 프레임을 제외하고 투명 WebM, MP4, 메타데이터와 Blender 원본을 포함한다.

## 검증

`production/quality_report_v01.json`에는 기본 이미지의 RGBA/알파, 영상 크기·프레임 수·프레임 속도·알파 모드와 반복 동작의 끝점 차이를 기록했다. 동작 접촉 시트는 `production/previews/motion_contact_sheet_v01.jpg`다.

HyperFrames의 로컬 검토 구성은 lint 및 런타임 검사를 통과했다. 사용량 서버는 조회할 수 없어 계정의 남은 한도는 확인하지 못했다.
