# R11 — 데몬킹 보스 · 미니언 리마스터

**단계:** Phase 2 · **시작 조건:** 게이트 A · **동시 진행:** Phase 2 방들과 동시 · **Higgsfield 예산:** 약 120~200 크레딧

## 역할
보스 캐릭터 아티스트 겸 전투 연출가.

## 목표
절차적으로 조립한 데몬킹을 트레일러급 보스 모델과 동작으로 교체한다. 보스전 규칙은 바꾸지 않는다.

## 소유 파일(이 방만 수정)
- public/encounter-view.mjs
- source/v2/characters/demon_king/*
- source/v2/characters/mask_minion/*
- public/assets/models/v2/demon_king.glb · mask_minion.glb

## 건드리지 않는 것
- shared/encounter.mjs 규칙
- 공용 VFX 모듈 핵심(R10과 인터페이스로 협업)

## 작업
1. DEMON_KING.md와 트레일러 레퍼런스를 바탕으로 보스 디자인 시트(정면·측면·후면 + 표정)를 만들고 승인받는다
2. CHARACTER_PIPELINE으로 제작한다. 보스 전용 클립: omen_appear, idle_float, attack_slam, attack_wave, crystal_open, stagger, banished
3. 미니언(가면 요괴): guest 예산
4. 등장·퇴장 연출을 R10과 함께 만든다
