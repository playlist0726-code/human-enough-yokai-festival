# R02 — 룩뎁 · 밤 조명, 대기, 컬러 그레이드

**단계:** Phase 1 · **시작 조건:** R01 병합 · **동시 진행:** R03 · R04 · R05와 동시 · **Higgsfield 예산:** 0~20 (하늘·원경 텍스처 이미지 생성 시)

## 역할
라이팅 아티스트 겸 테크니컬 아티스트(Three.js PBR, 후처리, 셰이더).

## 목표
지금의 "낮 같은 초록 공원"을 키아트의 "등불에 젖은 산꼭대기 밤 축제"로 바꾼다. 비용 대비 효과가 가장 큰 방이다. 모델을 바꾸지 않아도 분위기의 70%가 여기서 결정된다.

## 건드리지 않는 것
- 모델과 지형 메시(R04)
- UI(R05)

## 작업
1. 키아트(`submission-cover.png`, `festival.png`)를 분석해 조명 계획을 문서로 만든다(`docs/production/LIGHTING.md`): 달빛 방향·색, 앰비언트·반구광, 등불 빛 웅덩이, 노점 실내광, 노출, 화면의 명암 비율
2. 구현: 짙은 남색 하늘 돔 + 별 + 달 + 원경 산 실루엣과 호수 마을 불빛(카드 또는 저폴리), 높이 안개와 거리 안개, 차가운 달빛 그림자, 등불은 emissive와 "가짜 빛 웅덩이"(지면 데칼 또는 라이트맵 블렌드) + 근처의 실제 PointLight 몇 개(프로필별 개수 제한)
3. 후처리 체인: 블룸(임계값 높게, 등불·포션만), 컬러 그레이드 LUT(따뜻한 하이라이트, 푸른 섀도), 약한 비네트, 선택적 SSAO, SMAA. 프로필 high · balanced · mobile · light별로 정리한다
4. 불꽃놀이가 터질 때 하늘과 지면에 색광이 번지는 효과(R10 파티클과 연결하는 `render.flash(color, intensity)` API)
5. 캐릭터 가독성: 림라이트 또는 캐릭터 전용 fill(layers)로 밤에도 캐릭터 실루엣이 배경에서 분리되게 한다
6. 대표 장면 3곳(시작 지점, 노점 거리, 신사 앞)에서 키아트와 나란히 놓은 비교 이미지를 만들어 사용자 승인을 받는다
