# R06 — 캐릭터 · Pon + Kon

**단계:** Phase 2 · **시작 조건:** 게이트 A(R03 미즈 승인) · **동시 진행:** R06~R09 동시 (최대 4방) · **Higgsfield 예산:** 약 160~240 크레딧

## 역할
캐릭터 테크니컬 아티스트. R03이 확정한 파이프라인을 그대로 따른다.

## 목표
Pon, Kon를 미즈와 같은 품질·같은 규격으로 만든다. 새 방법을 발명하지 말고 `docs/production/CHARACTER_PIPELINE.md`를 따른다. 막히는 부분만 개선해 문서에 추가한다.

## 소유 파일(이 방만 수정)
- source/v2/characters/pon/*
- source/v2/characters/kon/*
- public/assets/models/v2/pon_yokai.glb · pon_reveal.glb
- public/assets/models/v2/kon_yokai.glb · kon_reveal.glb
- public/characters/defs/pon.json
- public/characters/defs/kon.json

## 건드리지 않는 것
- rig-v2.mjs 핵심 로직(필요하면 R03 소유자 대신 본부에 요청)
- 다른 캐릭터

## 작업
1. CHARACTER_PIPELINE.md를 처음부터 끝까지 읽고 미즈 결과물(게임 화면)을 확인한다
2. 캐릭터마다: 턴어라운드 → 3D 생성 → clean_character.py → rig_contract.py(+보조 뼈) → 14개 클립 → 리빌 소품 → defs JSON → 게임 확인
3. 폰: 배의 입(`x_belly_jaw`)이 열리고 닫히는 모프 또는 뼈, 꼬리 줄무늬. 콘: 늘어나는 목 체인 `x_neck_01..04`와 쌍꼬리, 보라색 도깨비불 꼬리 끝(알파 또는 R10 이펙트와 연결).
4. 캐릭터 성격 걸음과 `reveal_panic`은 아트 바이블 6장대로 차별화한다
5. 첫 캐릭터를 게임 화면으로 승인받은 뒤 두 번째를 진행한다
