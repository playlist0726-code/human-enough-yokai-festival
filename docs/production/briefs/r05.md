# R05 — UI · HUD · 2D 아트(로고, 아이콘, 메뉴, 로딩)

**단계:** Phase 1 · **시작 조건:** R01 병합 · **동시 진행:** R02 · R03 · R04와 동시 · **Higgsfield 예산:** 약 10~30 크레딧(+ sprite-gen용 OpenAI 또는 xAI 키 선택)

## 역할
게임 UI/UX 디자이너 겸 2D 아티스트(sprite-gen, CSS, 접근성).

## 목표
"웹페이지 같은 카드"를 "축제 종이와 나무패" UI로 바꾸고, 아이콘·로고·초상화를 하나의 세트로 만든다. 데스크톱과 휴대폰 모두.

## 소유 파일(이 방만 수정)
- public/index.html(마크업·텍스트)
- public/style.css
- public/stalls.css
- public/foundation-ui.mjs
- public/touch-controls.mjs(외형만)
- public/assets/ui/*
- source/v2/ui/*

## 건드리지 않는 것
- 게임 로직
- 3D 렌더링

## 작업
1. UX 감사: 현재 화면(타이틀, 캐릭터 선택, 로비, HUD, 저널, 결과, 휴대폰 레이아웃)의 문제를 우선순위로 정리한다(skills-ref/game-studios/skills/ux-review 참고 가능)
2. UI 키트: 색·타이포(로컬 폰트, 외부 요청 금지)·종이 패널 9-slice·버튼 상태·아이콘 그리드를 `docs/production/UI_KIT.md`와 CSS 변수로 정의한다
3. 아이콘 세트(포션, 홀리기, 결계, 점프, 공유, 넘기기, 도움, 스탬프 6종, 하트, 손님): 하나 먼저 승인 → 같은 스타일로 패밀리. 생성 → sprite-gen 컷아웃·정규화 → 128/64/32 크기의 SVG 또는 PNG
4. 타이틀 로고 워드마크(투명 배경)를 sprite-gen logo 흐름으로 정리한다. 기존 키아트의 로고 디자인을 기준으로 한다
5. 캐릭터 초상화: R03 이후 v2 모델 렌더로 교체할 수 있게 자리를 만든다(초기에는 기존 레퍼런스 이미지)
6. HUD 재배치: 밤 화면에서 읽히는 대비, 정보 우선순위(남은 시간 → 목표 → 영력 → 포션), 휴대폰 엄지 영역, 키 힌트 바 정리
7. 로딩 화면: 진행률과 팁, 무료 서버가 깨어나는 50초 대기를 위한 연출
