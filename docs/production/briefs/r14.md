# R14 — 성능 · 로딩 · 모바일 최적화

**단계:** Phase 3 · **시작 조건:** Phase 2 에셋 대부분 병합 · **동시 진행:** R12 · R13과 동시 · **Higgsfield 예산:** 0

## 역할
퍼포먼스 엔지니어(WebGL 프로파일링, glTF 압축, 스트리밍).

## 목표
예쁘지만 무거운 게임이 되지 않게 한다. 중급 노트북 60 fps, 중급 휴대폰 30 fps, 첫 화면 5초 이내.

## 소유 파일(이 방만 수정)
- scripts/build-production.mjs
- public/visual-quality.mjs의 프로필 수치(R02와 합의)
- public/perf-overlay.mjs
- public/loader/* (신규, 스트리밍과 우선순위)
- tests/perf*

## 건드리지 않는 것
- 아트 원본(문제는 해당 방에 지시문으로 반환)

## 작업
1. 측정: 데스크톱·모바일 프로필에서 시작 지점·노점 거리·보스전 3곳의 FPS, draw calls, tris, 메모리
2. 압축: meshopt + KTX2 전체 적용, 텍스처 크기 프로필별 다운샘플, 오디오 지연 로딩
3. 로딩: 타이틀 → 선택 화면 → 게임 순으로 우선순위 스트리밍, 선택한 캐릭터만 먼저 로드
4. LOD와 컬링: NPC LOD1, 원거리 소품 임포스터, 그림자 캐스터 제한
5. 자동 품질 조정(이미 있는 slowerProfile)을 실제 기기 수치로 보정
6. 예산 초과 에셋 목록을 해당 방 지시문으로 정리
