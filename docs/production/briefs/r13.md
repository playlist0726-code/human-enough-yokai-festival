# R13 — 사운드 · 음악

**단계:** Phase 3 · **시작 조건:** R01 병합(이벤트 버스) — 언제든 시작 가능 · **동시 진행:** 어느 Phase와도 동시 · **Higgsfield 예산:** 약 30~80 크레딧

## 역할
사운드 디자이너 겸 오디오 프로그래머(WebAudio).

## 목표
"전문가가 만든 게임"이라는 인상의 절반은 소리에서 나온다. 축제 앰비언스, 캐릭터 목소리 효과, UI 소리, 음악을 갖춘다.

## 소유 파일(이 방만 수정)
- public/audio/*
- public/assets/audio/*
- art/audio/*
- CREDITS.md(오디오 항목)

## 건드리지 않는 것
- 게임 로직

## 작업
1. 오디오 목록(`docs/production/AUDIO_LIST.md`): 이벤트 버스 이벤트별 큐 + 앰비언스 레이어(군중, 벌레, 북, 바람, 불꽃놀이) + 캐릭터별 짧은 목소리(웃음, 놀람) + UI
2. 음악: 타이틀, 축제 루프(일본 축제풍 오리지널), 보스전, 승리·패배 스팅어. Higgsfield generate_audio 또는 CC0 소스. 라이선스를 기록한다
3. 믹스: 버스(음악/효과/UI/앰비언스), 거리 감쇠, 덕킹, 모바일 첫 터치 잠금 해제, 압축 형식(ogg + m4a 폴백)
4. 설정의 소리 토글과 볼륨 슬라이더
