## 작업
1. 호스팅: Render 무료 플랜은 50초 이상 잠들기 때문에 출시용으로 부적합하다 → 유료 인스턴스나 다른 호스트를 비교하고 비용표를 만든다. 사용자 결정이 필요하다. 커스텀 도메인, 상태 확인, 오류 로깅(개인정보 최소화)
2. 배포 채널: itch.io(웹 빌드 + 멀티플레이 서버 URL) 우선, Steam(Electron 또는 Tauri 래퍼, 수수료와 심사)은 비용·일정 비교 후 사용자 결정
3. 스토어 자산: 캡슐 이미지, 스크린샷 8장, GIF 3개, 60초 트레일러(게임 플레이 녹화 기반), 소개 문구(영어), 태그
4. 법무: 생성 AI 도구별 상업 이용 약관 확인표, 서드파티 라이선스, 개인정보 고지(방 코드·닉네임만 수집), 연령 등급 설문
5. 포트폴리오 케이스 스터디: 문제(절차적 아트) → 파이프라인(컨셉 → 3D → 리그 → 런타임) → before/after → 기술적 결정 → 결과 수치. `baseline/`과 최종 캡처를 활용한다
6. 출시 체크리스트(skills-ref/game-studios/skills/launch-checklist)
