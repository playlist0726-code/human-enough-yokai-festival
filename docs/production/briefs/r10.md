# R10 — VFX · 게임필(변신, 홀리기, 결계, 포션, 불꽃놀이)

**단계:** Phase 2 · **시작 조건:** R01 병합 + R02 룩 방향 확정 · **동시 진행:** Phase 2 방들과 동시 · **Higgsfield 예산:** 약 30~80 크레딧

## 역할
VFX 아티스트 겸 게임필 디자이너(파티클, 셰이더, 플립북, 카메라 연출).

## 목표
게임의 핵심 순간이 "손맛 있게" 느껴지게 만든다. 지금 효과는 기능만 하고 감동이 없다.

## 소유 파일(이 방만 수정)
- public/fx/* (신규)
- public/transformation.mjs
- public/assets/fx/*
- art/fx/*

## 건드리지 않는 것
- 게임 규칙과 타이밍 값(shared/*)
- 캐릭터 클립(캐릭터 방)

## 작업
1. events.mjs 이벤트별 연출표(`docs/production/VFX_LIST.md`): 이벤트 → 파티클·셰이더·화면 효과·카메라 흔들림·히트스톱·UI 반응·사운드 큐 이름(R13이 사용)
2. 변신 장면(요괴 → 연기 펑 → 인간): 이 게임의 오프닝이다. 연기 플립북(sprite-gen video-loop 또는 생성 영상에서 추출) + 빛 링 + 카메라 연출
3. 홀리기(분홍·보라 나선 + 하트), 결계 돔(금빛 부적), 포션 줍기·마시기(유리 반짝임, 영력 게이지와 연결), 리빌 팝(요괴 부위가 튀어나올 때 "뿅"), 배달 성공(신사 포털 반응), 불꽃놀이(하늘 + R02의 render.flash)
4. 데몬킹 공격 예고(주황 원, 보라 충격파)를 읽기 쉽고 공정하게 만든다(R11과 협업)
5. 발자국 먼지, 착지 눌림, 점프 잔상 같은 작은 피드백
6. 프로필별 파티클 예산(mobile에서는 절반)
