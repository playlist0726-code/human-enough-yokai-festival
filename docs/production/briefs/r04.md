# R04 — 환경 아트 · 축제 키트(노점·등불·도리이·신사·길)

**단계:** Phase 1 · **시작 조건:** R01 병합(조명은 R02와 맞춰 감) · **동시 진행:** R02 · R03 · R05와 동시 · **Higgsfield 예산:** 약 50~120 크레딧(블렌더 우선)

## 역할
환경 아티스트 겸 레벨 아티스트(모듈러 키트, 인스턴싱, 텍스처 아틀라스).

## 목표
절차적으로 만든 상자형 노점과 단순한 등불·돌길을 `festival.png` 수준의 손맛 있는 키트로 교체한다. **충돌 박스와 동선은 그대로 둔다.**

## 소유 파일(이 방만 수정)
- public/festival.mjs
- public/festival-scenery.mjs
- public/foliage.mjs
- public/assets/env/v2/*
- art/environment/v2/*

## 건드리지 않는 것
- shared/world.mjs의 충돌·좌표(바꿔야 하면 본부에 요청)
- 조명·후처리(R02)
- 미니게임 내부 장면(R12)

## 작업
1. 에셋 목록(`art/environment/v2/manifest.json`): 노점 6종(코르크 사격, 금붕어, 고리던지기, 타코야키, 제비뽑기, 빙수) + 공용 노점 부품, 종이 등불, 석등, 도리이, 신사 정문(요괴 세계 포털 자리), 난간, 계단, 돌길 타일 5종, 바위, 벚나무·소나무·대나무, 깃발·현수막(무늬 텍스처), 큰북 망루
2. 히어로 에셋 1개(금붕어 노점)를 먼저 만들어 R02 조명 아래 게임 카메라로 승인받는다 → 같은 텍스처 아틀라스와 비율로 패밀리 제작
3. 제작 방법은 **블렌더 우선**이다. 노점·등불·도리이·난간·돌길·계단처럼 기하학적인 것은 Blender(bpy) 스크립트로 직접 모델링한다(베벨, 두께 과장, 아틀라스 UV, 무늬와 마모는 텍스처로). 텍스처와 무늬는 Higgsfield 이미지 생성(장당 0.25cr)으로 만든다. 3D 생성은 나무·바위·소품처럼 유기적인 형태에만 쓴다(Tripo/Hunyuan LowPoly → Blender 정리). 반복 소품은 InstancedMesh
4. 지면: 잔디를 밤에 어울리는 어두운 이끼·흙 톤의 페인터리 텍스처로 바꾸고, 돌길에 높낮이·마모·이끼를 넣는다. 원경(호수 마을, 폭포, 산)은 R02의 하늘과 맞춘다
5. 시야 처리: 머리 위 구조물 페이드(기존 기능)를 유지하고, 카메라 충돌과 맞는지 확인한다
